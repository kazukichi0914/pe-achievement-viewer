# pe-achievement-viewer
Google プロダクト エキスパートの達成状況を、ツールバーのボタン1つでポップアップ表示する Chrome 拡張機能（非公式）。製品ごとのレベル・ポイント・次のレベルまでの進捗・失効間近のポイントを確認できます。 / Unofficial Chrome extension that shows your Google Product Experts achievements in a popup with one click: level, points, progress to the next level, and expiring points for each product.
